Generated by `npm run inventory` from the live route table; do not edit by hand. "Public" routes need no sign-in (they are protected by signatures, tokens or rate limits instead). Otherwise send `Authorization: Bearer <accessToken>`; a route with roles refuses everyone else with 403, a route without roles accepts any signed-in user.
